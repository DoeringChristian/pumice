# Pumice — Plan

Pumice is a local-first, extensible markdown note-taking app in the spirit of Obsidian:
same markdown dialect, a plugin system in which the core features are themselves plugins,
a first-class Excalidraw integration, desktop + mobile, and real-time collaboration.

## Decisions

| ID  | Decision                                                                                                                                                                                                                                                                                                | Rationale (short)                                                                                                                                                                                                                                                                      |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | TypeScript everywhere, pnpm monorepo, Vite                                                                                                                                                                                                                                                              | Plugin ecosystem, Excalidraw, CodeMirror all live in TS/JS.                                                                                                                                                                                                                            |
| D2  | **Electron** on desktop, **Capacitor** on iOS/Android, one shared web core                                                                                                                                                                                                                              | Consistent Chromium on desktop (Linux WebKitGTK is the weak spot for Tauri); iOS forces WebKit for everyone, Capacitor is the mature mobile shell.                                                                                                                                     |
| D3  | All OS access behind a `Platform` interface                                                                                                                                                                                                                                                             | Shell is swappable; plugins never touch Node/Capacitor directly.                                                                                                                                                                                                                       |
| D4  | **CodeMirror 6** + `@lezer/markdown` for editing; **micromark/mdast** for rendering & indexing; shared conformance suite                                                                                                                                                                                | CM6 is the only serious base for live preview; mdast for a rich AST ecosystem.                                                                                                                                                                                                         |
| D5  | Kernel is minimal; **every feature is a plugin**, including editor, workspace and vault                                                                                                                                                                                                                 | Core features prove the API; any core plugin can be replaced.                                                                                                                                                                                                                          |
| D6  | **Own plugin API**, framework-agnostic (DOM containers); Obsidian-compat shim after v1                                                                                                                                                                                                                  | Clean, typed, platform-neutral (mobile has no Node), sandbox-ready.                                                                                                                                                                                                                    |
| D7  | React used internally and offered as a shared module                                                                                                                                                                                                                                                    | Excalidraw needs it anyway; plugins don't bundle their own copy.                                                                                                                                                                                                                       |
| D8  | Note identity = frontmatter `id`; links written as `[[id\|Name]]`, resolved by id with name fallback                                                                                                                                                                                                    | Renames/moves never break links; no rewrite cascade.                                                                                                                                                                                                                                   |
| D9  | Files are the source of truth for local vaults; every index is a disposable cache outside the vault                                                                                                                                                                                                     | No index files in the vault; delete-and-rebuild is always safe.                                                                                                                                                                                                                        |
| D10 | Documents are always **Yjs** docs in memory; persistence providers write files and (for shared vaults) sync                                                                                                                                                                                             | One editing path for local and collaborative notes.                                                                                                                                                                                                                                    |
| D11 | Collaboration via a self-hostable sync server (Yjs protocol)                                                                                                                                                                                                                                            | Real-time, offline-first, conflict-free merging.                                                                                                                                                                                                                                       |
| D12 | Excalidraw plugin reads/writes the Obsidian Excalidraw `.excalidraw.md` format                                                                                                                                                                                                                          | Existing vaults open unchanged.                                                                                                                                                                                                                                                        |
| D14 | _(M5, decides the open question in 05)_ Collaboration ships **server-trusted** (TLS + server-side storage) behind the versioned envelope; E2EE comes later as a new envelope version                                                                                                                    | Keeps server-side compaction, history and snapshots simple for the first beta. The envelope carries a version and per-document payloads, so encrypted payloads can be introduced without breaking clients.                                                                             |
| D13 | _(revises the index part of 01/04, M2)_ The metadata index is **in memory** (maps + MiniSearch full-text), parsed in a worker, cached as a JSON snapshot in app storage — not SQLite-WASM                                                                                                               | Editor decorations and link resolution need synchronous lookups; measured on 10k notes: cold index 3.1 s, warm start 77 ms, search 5 ms. No WASM/OPFS dependency on mobile webviews. The `MetadataIndex` API is unchanged, so SQLite can come back behind it if vaults outgrow memory. |
| D15 | _(M7)_ Excalidraw is built from a **Pumice fork** (upstream master + the MathJax subtypes PR #6037/#6936, rebased) vendored as a git submodule                                                                                                                                                          | Native LaTeX in drawings; the upstream PR has been open since 2022. Drawings stay readable by stock Excalidraw (math shows as LaTeX source).                                                                                                                                           |
| D16 | _(M7)_ **Comments live in sidecar files** (`.pumice/comments/<note path>.json`) anchored by quote + context, not inline in the markdown                                                                                                                                                                 | Notes stay clean for Obsidian, agents and git; anchors survive outside edits by re-finding the quote.                                                                                                                                                                                  |
| D17 | _(M7)_ **Agents via the Agent Client Protocol** (ACP), spawning the user's installed CLI (Claude Code, Codex, Gemini CLI)                                                                                                                                                                               | Uses existing subscriptions/logins without API keys; one protocol for all agents; agent edits go through `Documents` so they merge live.                                                                                                                                               |
| D18 | _(M7, replaces D8)_ Links are **Obsidian-style `[[Name]]`** in the core (resolved by path, name, alias; rewritten on rename). Note IDs and `[[id\|Name]]` links are an **optional plugin** (`core.ids`) on top, through a link-resolver hook in the index and a link-formatter hook in the links plugin | Natural, readable links that match Obsidian exactly; vaults stay free of `id` properties unless the user opts in. ID links keep resolving when the plugin is on.                                                                                                                       |

Decisions are revisited only with a written reason in the relevant document.
