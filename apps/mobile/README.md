# Pumice mobile (iOS & Android)

The same app bundle as desktop, hosted in [Capacitor](https://capacitorjs.com) (docs/plan/07).
The vault is a folder of plain files on the device, accessed through the native `PumiceFs`
plugin in `native/`.

## Android

The Android project is in `android/` (generated by Capacitor, committed). It needs a JDK (17+)
and the Android SDK (platform 34, build-tools 34):

```sh
brew install openjdk@21 && brew install --cask android-commandlinetools
export JAVA_HOME=/opt/homebrew/opt/openjdk@21 ANDROID_HOME=/opt/homebrew/share/android-commandlinetools
sdkmanager "platform-tools" "platforms;android-34" "build-tools;34.0.0"

npm run android:apk -w @pumice/mobile     # → android/app/build/outputs/apk/debug/app-debug.apk
npm run android -w @pumice/mobile         # or open it in Android Studio
```

`native/android/PumiceFsPlugin.kt` is the source of the native plugin; `npm run native` copies it
into the Android project (the build scripts do this for you).

**Vaults on Android.** Vaults live in the app's storage (`Android/data/app.pumice.mobile/files/`,
visible to file managers and over USB), or in any folder on the device — for example an Obsidian
vault you sync there. Opening a device folder needs the "all files access" permission (asked for
when you first use it), because plain file access is far faster than Android's document
framework for thousands of notes. Switch vaults with the folder button in the bottom bar.

## iOS (needs Xcode; not built yet)

```sh
npm exec -w @pumice/mobile -- cap add ios          # creates ios/
```

Copy `native/ios/PumiceFsPlugin.swift` into `ios/App/App/` (add it to the App target in Xcode;
Capacitor 6 registers `CAPBridgedPlugin` classes automatically). In `Info.plist` set
`UIFileSharingEnabled` and `LSSupportsOpeningDocumentsInPlace` to `YES` so the vault shows in the
Files app. Vault switching is not implemented on iOS yet.

Status: Android builds and was run in an emulator (create notes, create and switch vaults, open
a device folder). iOS has never been built.
